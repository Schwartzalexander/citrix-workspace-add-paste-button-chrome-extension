# citrix-workspace-add-paste-button-chrome-extension
A chrome extension, which adds a paste button to Citrix Workspace in the 2FA block.

## What it does

On the Citrix Workspace one-time-password page, the extension adds a `Paste OTP and continue` button next to the normal submit button. Clicking it reads the clipboard, inserts the OTP into the password field, and submits the form.

## Install locally

1. Open `chrome://extensions`.
2. Enable `Developer mode`.
3. Click `Load unpacked`.
4. Select this repository folder.
